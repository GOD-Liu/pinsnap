Privacy Policy

Effective Date: November 25, 2026

1. Local-First Data Processing

PinSnap is designed as a local-first Chrome extension. Screenshots, DOM selectors, computed CSS properties, design overlay images, console errors, and network failure summaries are processed locally inside your browser and stored only in your local extension storage when needed. PinSnap does not operate tracking analytics, telemetry, or remote screenshot storage servers.

2. Third-Party Requests (User-Initiated Only)

  • GitHub / Linear Integrations: Only triggered when you explicitly configure your own personal API token and click "Create Issue". Data is sent directly from your browser to GitHub or Linear.
  • Pro License Validation: When you enter a Pro license key in Options, PinSnap sends only the license key and device instance identifier to our licensing endpoint (api.pinsnap.space) and payment provider (Creem) over HTTPS to verify license status.

3. Data Retention & Contact

You may clear all locally saved settings, tokens, or license keys at any time from the PinSnap Options page or by uninstalling the extension. For privacy questions, contact us at nibujimo6@gmail.com.
